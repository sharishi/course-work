## Data structures: Lists, tuples, sets, dictionaries, and comprehensions

### Списки (Lists)
Списки — это упорядоченные изменяемые коллекции элементов.
Они могут содержать элементы разных типов и изменяться после создания.
1. Создание списка:
```python
my_list = [1, 2, 3, "hello", 3.14]
```
2. Доступ к элементам:
```python
first_element = my_list[0]   # 1
last_element = my_list[-1]    # 3.14
```
3. Изменение элементов:
```python
my_list[1] = "world"
```
4. Методы списка:
```python
my_list.append(42)        # Добавляет элемент в конец
my_list.remove("hello")   # Удаляет первый найденный элемент
length = len(my_list)     # Длина списка
```
### Кортежи (Tuples)
Кортежи — это упорядоченные неизменяемые коллекции элементов.
Они используются для хранения множества значений, которые не должны изменяться.

1. Создание кортежа:
```python
my_tuple = (1, 2, 3, "hello", 3.14)
```
2.Доступ к элементам:
```python
first_element = my_tuple[0]   # 1
```
Кортежи не поддерживают изменение элементов.

### Множества (Sets)
Множества — это неупорядоченные коллекции уникальных элементов. 
Они не допускают дублирования значений.

1. Создание множества:
```python
my_set = {1, 2, 3, "hello"}
```
2. Операции с множествами:

```python
my_set.add(4)                # Добавляет элемент
my_set.remove(2)             # Удаляет элемент (если он существует)
is_member = 3 in my_set      # Проверяет наличие элемента
```
3. Операции над множествами:
```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}
union = set1 | set2          # Объединение
intersection = set1 & set2   # Пересечение
difference = set1 - set2     # Разность
```
###  Словари (Dictionaries)
Словари — это неупорядоченные коллекции пар "ключ-значение".
Ключи должны быть уникальными и неизменяемыми.

1. Создание словаря:
```python
my_dict = {"name": "Alice", "age": 25, "city": "Moldova"}
```
2. Доступ к элементам:
```python
name = my_dict["name"]       # "Alice"
```
3. Изменение значений:
```python
my_dict["age"] = 26
```
4. Методы словаря:
```python
keys = my_dict.keys()       # Возвращает список ключей
values = my_dict.values()   # Возвращает список значений
items = my_dict.items()     # Возвращает пары ключ-значение
```
### 5. Генераторы (Comprehensions)
Генераторы позволяют создавать списки, множества и словари в компактной
и выразительной форме.

1. Списковые генераторы:

2. Генераторы множеств:

3. Генераторы словарей:

Генераторы позволяют легко и эффективно создавать коллекции данных с использованием
условий и циклов.

# Functions and lambda expressions: Creating and using functions, and understanding lambda expressions and their use in functional programming
### Функции в Python
Функция — это блок кода, который выполняет определённое действие и может быть вызван многократно в разных местах программы. Функции позволяют структурировать код и избегать его дублирования
#### Неопределённое количество аргументов
Если нужно передать неопределённое количество аргументов, используется символ * для позиционных и ** для именованных аргументов.
- Позиционные аргументы:
```python
def add(*numbers):
    return sum(numbers)

print(add(1, 2, 3))  # Вывод: 6
```
- Именованные аргументы:
```python
def print_info(**info):
    for key, value in info.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25)
```
Именованные аргументы (или аргументы с ключевыми словами) позволяют передавать значения параметров по их именам, а не по порядку. Вы явно указываете, какому параметру функции должно быть присвоено значение.
```python
def greet(name, age):
    print(f"Hello, {name}! You are {age} years old.")

greet(name="Alice", age=25)  # Именованный вызов аргументов
greet(age=30, name="Bob")    # Можно менять порядок
```
- Позиционный аргумент не может следовать за именованным
### Лямбда-выражения
Лямбда-выражения — это компактные анонимные функции, которые могут иметь любое количество аргументов, но содержат только одно выражение. Их часто используют для кратковременных операций, где не нужно определять полноценную функцию.
```python
lambda arguments: expression
```
#### Использование лямбда-выражений в функциональном программировании
Лямбда-выражения часто используются вместе с функциями высшего порядка, такими как map(), filter() и reduce().

1. Пример с map():
Функция map() применяет лямбда-функцию ко всем элементам последовательности.
```python
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # Вывод: [1, 4, 9, 16]
```
2. Пример с filter():
Функция filter() отбирает элементы последовательности, которые удовлетворяют условию, заданному в лямбда-функции.
```python
numbers = [1, 2, 3, 4, 5]
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # Вывод: [2, 4]
```
3. Пример с reduce():
Функция reduce() применяется к элементам последовательности и сводит их к одному значению. Для этого нужно импортировать её из модуля functools.
```python
from functools import reduce

numbers = [1, 2, 3, 4]
product = reduce(lambda x, y: x * y, numbers)
print(product)  # Вывод: 24
```
#### Заключение
- Функции позволяют структурировать и переиспользовать код. Они могут принимать аргументы, возвращать значения и быть вызваны многократно.
- Лямбда-выражения — это компактные анонимные функции, которые особенно полезны при работе с функциями высшего порядка.

## Основные концепции ООП:
Объектно-ориентированное программирование (ООП) — это парадигма программирования, в которой основными единицами кода являются объекты, созданные на основе классов. ООП в Python предоставляет возможности для создания и управления объектами, а также организации кода с помощью концепций наследования, инкапсуляции и полиморфизма.

#### Основные концепции ООП:
- Классы и объекты
- Атрибуты и методы
- Наследование

### Классы и объекты
- Класс — это шаблон или схема для создания объектов (экземпляров класса).
- Объект — это экземпляр класса с определёнными данными и методами.\
##### Создание класса:
Класс создаётся с помощью ключевого слова class.

```python
class Dog:
    # Конструктор класса (метод __init__) для инициализации атрибутов
    def __init__(self, name, breed):
        self.name = name  # Атрибут экземпляра
        self.breed = breed
    
    # Метод экземпляра
    def bark(self):
        return f"{self.name} says: Woof!"

# Создание объекта (экземпляра класса)
my_dog = Dog("Buddy", "Golden Retriever")

# Доступ к атрибутам и методам
print(my_dog.name)      # Вывод: Buddy
print(my_dog.bark())    # Вывод: Buddy says: Woof!
```

### Атрибуты и методы
- Атрибуты — это переменные, которые принадлежат объекту или классу.
- Методы — это функции, которые принадлежат классу и могут взаимодействовать с его объектами.
##### Атрибуты:
- Атрибуты экземпляра — создаются в методе __init__ и уникальны для каждого объекта.
- Атрибуты класса — определяются внутри класса, но вне методов, и общие для всех экземпляров.\
Пример атрибутов класса:
```python
class Dog:
    species = "Canis familiaris"  # Атрибут класса (общий для всех объектов)
    
    def __init__(self, name, breed):
        self.name = name           # определение атрибута экземпляра
        self.breed = breed
В этом примере name, breed — это атрибуты экземпляра класса Dog.
# Создание объектов
dog1 = Dog("Buddy", "Golden Retriever")
dog2 = Dog("Charlie", "Poodle")

print(dog1.species)  # Вывод: Canis familiaris
print(dog2.species)  # Вывод: Canis familiari
```
### Наследование
Наследование позволяет одному классу наследовать атрибуты и методы другого класса. Это позволяет использовать повторно код и расширять функциональность.

Пример наследования:
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound"

# Класс Dog наследует от класса Animal
class Dog(Animal):
    def speak(self):
        return f"{self.name} barks"

# Класс Cat наследует от класса Animal
class Cat(Animal):
    def speak(self):
        return f"{self.name} meows"

dog = Dog("Buddy")
cat = Cat("Whiskers")

print(dog.speak())  # Вывод: Buddy barks
print(cat.speak())  # Вывод: Whiskers meows
```
Здесь класс Dog и класс Cat наследуют атрибуты и методы класса Animal, но переопределяют метод speak().

### Инкапсуляция
Инкапсуляция — это скрытие внутренней реализации объекта  и предоставление доступа только к нужной информации через методы.\
Приватные атрибуты в Python обозначаются символом подчеркивания _ или __ перед именем переменной.\
Пример инкапсуляции:
```python
class Person:
    def __init__(self, name, age):
        self.name = name       # Публичный атрибут
        self.__age = age       # Приватный атрибут

    def get_age(self):         # Публичный метод для доступа к приватному атрибуту
        return self.__age

    def set_age(self, age):    # Метод для изменения приватного атрибута
        if age > 0:
            self.__age = age

person = Person("Alice", 30)
print(person.name)          # Доступ к публичному атрибуту
print(person.get_age())     # Доступ к приватному атрибуту через метод

person.set_age(35)          # Изменение приватного атрибута
print(person.get_age())     # Вывод: 35
```
Здесь __age — приватный атрибут, доступ к которому осуществляется через публичные методы get_age() и set_age().

- Одно подчеркивание (_):\
Указывает на то, что переменная или метод является приватным по соглашению.\
Не является строгой защитой и доступен извне, хотя не рекомендуется использовать напрямую.
- Два подчеркивания (__):\
Используется для создания более защищённых (инкапсулированных) атрибутов или методов.\
Включает механизм "name mangling", который изменяет имя переменной для предотвращения её случайного использования или переопределения в наследующих классах.
### Полиморфизм
Полиморфизм позволяет методам с одинаковыми именами вести себя по-разному в зависимости от класса объекта, который их использует.

Пример полиморфизма:
```python
class Animal:
    def speak(self):
        raise NotImplementedError("Subclass must implement abstract method")

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

animals = [Dog(), Cat()]

for animal in animals:
    print(animal.speak())  # Вывод: Woof!, Meow!
```
Здесь метод speak() реализован в разных классах по-своему, и полиморфизм позволяет вызывать метод для разных объектов без необходимости уточнения их типа.

# Error handling: Understanding and handling exceptions using try, except, and finally blocks
Обработка ошибок в Python осуществляется с помощью исключений. Исключения позволяют управлять ошибками и непредвиденными ситуациями, которые могут возникнуть в процессе выполнения программы. В Python для обработки исключений используются блоки try, except, и finally.

Основные компоненты обработки исключений:
- try: Блок кода, в котором может возникнуть исключение.
- except: Блок кода, который выполняется, если в блоке try возникает исключение.
- finally: Блок кода, который выполняется в любом случае, независимо от того, возникло исключение или нет.

```python
try:
    # Код, который может вызвать исключение
    result = 10 / 0
except ZeroDivisionError:
    # Код, который выполняется при возникновении исключения
    print("Ошибка: Деление на ноль!")
finally:
    # Код, который выполняется в любом случае
    print("Блок finally выполняется всегда.")
```

- Обработка нескольких исключений:
Вы можете обрабатывать несколько типов исключений, указав несколько блоков except.

```python
try:
    result = int("string")
except ValueError:
    print("Ошибка: Невозможно преобразовать строку в число.")
except ZeroDivisionError:
    print("Ошибка: Деление на ноль!")
    
    or 
    
    try:
    result = 10 / 0
except (ZeroDivisionError, ValueError) as e:
    print(f"Произошла ошибка: {e}")
    
```

- Использование else:

Блок else может быть использован вместе с try и except. Этот блок выполняется, если исключение **не произошло**.

```python
try:
    result = 10 / 2
except ZeroDivisionError:
    print("Ошибка: Деление на ноль!")
else:
    print(f"Результат: {result}")
finally:
    print("Блок finally выполняется всегда.")
```
- Создание собственных исключений:

Вы можете создавать свои собственные классы исключений, наследуя их от встроенного класса Exception.

```python
class MyCustomError(Exception):
    pass

try:
    raise MyCustomError("Это пользовательская ошибка.")
except MyCustomError as e:
    print(f"Поймано исключение: {e}")
    
```
#### Ре-выброс исключений
Вы можете использовать raise без аргументов внутри блока except, чтобы заново выбросить пойманное исключение и передать его на уровень выше.

```python
try:
    # Код, который может вызвать исключение
    result = 10 / 0
except ZeroDivisionError:
    print("Произошло деление на ноль")
    raise  # Реброс исключения
```
Объяснение:

'raise' перехватывает текущее исключение и передает его на уровень выше, чтобы оно могло быть обработано другими блоками except или выйти из программы.
Ключевое слово raise в Python используется для генерации (или "выбрасывания") исключения. Это позволяет сообщить о возникновении ошибки или необычной ситуации, которую необходимо обработать. raise может использоваться для выбрасывания встроенных или пользовательских исключений.
#### Заключение
- try: Определяет блок кода, в котором могут возникнуть ошибки.
- except: Обрабатывает исключения, возникшие в блоке try.
- finally: Выполняется всегда, независимо от того, возникло исключение или нет.
- else: Выполняется, если исключение не возникло в блоке try.

Эти конструкции позволяют эффективно управлять ошибками и обеспечивать выполнение завершающих действий, таких как освобождение ресурсов, независимо от результата выполнения основного кода.

# Regular expressions: Using regular expressions for pattern matching and text manipulation.

Регулярные выражения (регэкспы) — мощный инструмент для поиска, проверки и манипулирования текстом в Python. Они позволяют искать текстовые шаблоны, заменять их или извлекать данные, соответствующие определенным шаблонам.

В Python для работы с регулярными выражениями используется модуль re.

#### Основные функции модуля re:
- re.match()
- re.search()
- re.findall()
- re.finditer()
- re.sub()
- re.split()

1. re.match()

Функция re.match() проверяет, соответствует ли начало строки заданному шаблону.

```python
import re

pattern = r'\d+'  # Шаблон для поиска одной или более цифр
text = '123abc'

match = re.match(pattern, text)
if match:
    print("Совпадение найдено:", match.group())  # Вывод: 123
else:
    print("Совпадение не найдено")
```

2. re.search()

Функция re.search() ищет первое совпадение шаблона в строке и возвращает объект совпадения.

```python
import re

pattern = r'\d+'
text = 'abc123def'

search = re.search(pattern, text)
if search:
    print("Совпадение найдено:", search.group())  # Вывод: 123
else:
    print("Совпадение не найдено")
```
3. re.findall()

Функция re.findall() возвращает все совпадения шаблона в строке в виде списка.

```python
import re

pattern = r'\d+'
text = 'abc123def456ghi789'

matches = re.findall(pattern, text)
print("Совпадения найдены:", matches)  # Вывод: ['123', '456', '789']
```
4. re.finditer()

Функция re.finditer() возвращает итератор объектов совпадений для всех вхождений шаблона в строке.

```python
import re

pattern = r'\d+'
text = 'abc123def456ghi789'

matches = re.finditer(pattern, text)
for match in matches:
    print("Совпадение найдено:", match.group())  # Вывод: 123, 456, 789
```

## Итератор 
##### Итератор в Python — это объект, который поддерживает протокол итерации, то есть реализует методы `__iter__()` и `__next__()`. Он позволяет последовательно проходить по элементам коллекции (например, списка, кортежа, множества или словаря) без необходимости доступа к элементам по индексам.

Основные понятия:

1. **Итератор** — объект, который возвращает следующий элемент последовательности при вызове метода `__next__()`. Когда элементы заканчиваются, возникает исключение `StopIteration`.

2. **Итерируемый объект** — объект, из которого можно получить итератор. Для этого используется функция `iter()`, которая вызывает метод `__iter__()` объекта.

Пример итератора:

```python
my_list = [1, 2, 3]
iterator = iter(my_list)  # Создаем итератор из списка

print(next(iterator))  # 1
print(next(iterator))  # 2
print(next(iterator))  # 3
# Если вызвать next() снова, произойдет StopIteration
```

### Преимущества итераторов:
- Итераторы ленивы: элементы вычисляются только по мере необходимости, что позволяет экономить память.
- Их можно использовать для работы с большими коллекциями данных, так как они не требуют загрузки всей коллекции в память.

Итераторы часто используются в циклах `for`, где Python неявно вызывает функции `iter()` и `next()` для прохода по итерируемому объекту.

5. re.sub()

Функция re.sub() заменяет все совпадения шаблона в строке на заданный текст.
```
import re

pattern = r'\d+'
replacement = '#'
text = 'abc123def456ghi789'

result = re.sub(pattern, replacement, text)
print("Результат замены:", result)  # Вывод: abc#def#ghi#
```

6. re.split()

Функция re.split() разбивает строку по шаблону и возвращает список.
```
import re

pattern = r'\d+'
text = 'abc123def456ghi789'

result = re.split(pattern, text)
print("Результат разделения:", result)  # Вывод: ['abc', 'def', 'ghi', '']
```

### Основные конструкции шаблонов
- r'\d+': Один или более цифровых символов.
- r'\w+': Один или более буквенно-цифровых символов.
- r'\s+': Один или более пробельных символов.
- r'\bword\b': Слово "word" с границами слова.
- r'[a-z]+': Один или более строчных букв от a до z.
- r'(abc|def)': Либо "abc", либо "def".

## Использование групп и ссылок
- Группы: Круглые скобки () позволяют группировать части шаблона.
- Ссылки на группы: Используются для получения подстрок из найденных групп.

Пример с группами:
```
import re

pattern = r'(\d+)-(\d+)'
text = '123-456'

match = re.match(pattern, text)
if match:
    print("Группа 1:", match.group(1))  # Вывод: 123 и ссылка на группу 1
    print("Группа 2:", match.group(2))  # Вывод: 456 и ссылка на группу 2
```

### Ссылки на группы

В регулярных выражениях можно использовать ссылки на группы, чтобы ссылаться на ранее найденные подстроки. Это бывает полезно, когда требуется найти одинаковые или повторяющиеся элементы в строке. Ссылки на группы обозначаются как `\1`, `\2` и т.д., где номер соответствует порядковому номеру группы в шаблоне.

Пример использования ссылки на группу:
```python
import re

pattern = r'(\b\w+)\s+\1'  # Находит повторяющиеся слова
text = 'hello hello world'

match = re.search(pattern, text)
if match:
    print("Повторяющееся слово:", match.group(1))  # Вывод: hello
```

В этом примере:
- `(\b\w+)` — первая группа, которая находит слово.
- `\1` — ссылка на первую группу, означающая, что после пробела должно быть такое же слово.

Таким образом, шаблон находит повторяющиеся подряд слова, такие как "hello hello".
#### Заключение

Регулярные выражения позволяют гибко и мощно управлять текстом. Основные функции модуля re помогут вам искать, извлекать, заменять и разделять текстовые данные, используя шаблоны. Регулярные выражения особенно полезны для обработки строк, проверки форматов данных и извлечения информации.

# Web scraping: Extracting data from websites using libraries like Selenium or BeautifulSoup and requests.
**Web scraping** — это процесс извлечения данных с веб-сайтов. В Python для выполнения web scraping часто используются библиотеки, такие как requests, BeautifulSoup, и Selenium. Вот как использовать каждую из них для извлечения данных с веб-сайтов.

## Использование requests и BeautifulSoup
- requests — это библиотека для отправки HTTP-запросов и получения данных с веб-сайтов.
- BeautifulSoup — это библиотека для парсинга HTML и XML документов. В комбинации эти библиотеки позволяют извлекать и обрабатывать данные с веб-страниц.

Пример: **Извлечение заголовков с веб-страницы***
```
import requests
from bs4 import BeautifulSoup

# Отправка GET-запроса на веб-страницу
response = requests.get('https://example.com')

# Проверка статуса ответа
if response.status_code == 200:
    # Парсинг HTML-кода страницы
    soup = BeautifulSoup(response.text, 'html.parser')
    
    # Извлечение заголовков (например, заголовков первого уровня)
    headers = soup.find_all('h1')
    
    for header in headers:
        print(header.text)
else:
    print("Ошибка при запросе страницы:", response.status_code)
```
#### Основные шаги:

- Отправляем HTTP-запрос с помощью requests.get().
- Получаем HTML-код ответа.
- Используем BeautifulSoup для парсинга HTML.
- Находим нужные элементы (например, заголовки) и извлекаем их текст.
## Использование Selenium
Selenium — это библиотека для автоматизации веб-браузеров. Она позволяет взаимодействовать с динамическими страницами, где контент загружается с помощью JavaScript.

Пример: **Извлечение данных с динамической страницы**
```
from selenium import webdriver
from selenium.webdriver.common.by import By

# Настройка веб-драйвера (например, для Chrome)
driver = webdriver.Chrome()  # Путь к драйверу может быть указан явно

# Открытие веб-страницы
driver.get('https://example.com')

# Поиск элемента на странице
element = driver.find_element(By.TAG_NAME, 'h1')
print("Заголовок страницы:", element.text)

# Закрытие браузера
driver.quit()
```
#### Основные шаги:

- Настройка веб-драйвера для браузера (например, Chrome, Firefox).
- Открытие веб-страницы с помощью метода get().
- Поиск элементов на странице и извлечение данных.
- Закрытие браузера после завершения работы.

#### Сравнение requests + BeautifulSoup и Selenium
1. requests + BeautifulSoup:
- Подходит для статических страниц, где HTML-код можно получить сразу.
- Легче и быстрее в работе, так как не требует запуска браузера.
2. Selenium:
- Подходит для динамических страниц, где контент загружается или изменяется с помощью JavaScript.
- Позволяет взаимодействовать с веб-страницами, как это делает пользователь (например, заполнять формы, нажимать кнопки).
#### Заключение
Для web scraping в Python вы можете использовать requests и BeautifulSoup для статического контента или Selenium для взаимодействия с динамическими страницами. Оба подхода позволяют эффективно извлекать данные с веб-сайтов, но выбор инструмента зависит от сложности и динамичности целевых страниц.

# APIs: Interacting with APIs to fetch and process data from external

### Конспект по API и взаимодействию с ними

**1. Что такое API?**
- **API (Application Programming Interface)** — это интерфейс для взаимодействия различных программных компонентов. Он позволяет одним приложениям получать доступ к функционалу других систем или данных через стандартизированные запросы.
- **Пример:** API погодной службы может предоставить данные о текущей погоде, которые ваше приложение может использовать для отображения прогноза.

**2. Типы API:**
- **REST API (Representational State Transfer):**
  - Самый распространенный тип API.
  - Использует HTTP-запросы (GET, POST, PUT, DELETE) для взаимодействия с ресурсами.
  - **Пример:** Запрос на получение данных о пользователе: `GET /users/123`
  
- **SOAP (Simple Object Access Protocol):**
  - Больше используется в корпоративных приложениях.
  - Формат передачи данных — XML.
  - **Пример:** SOAP-запрос для получения данных может выглядеть сложнее и более структурированно, чем у REST.

- **GraphQL:**
  - Позволяет клиенту определять, какие именно данные нужны.
  - Более гибкий по сравнению с REST, так как позволяет запрашивать только необходимые поля.
  - **Пример:** `query { user(id: 123) { name, email } }`

**3. Основные компоненты REST API:**
- **HTTP методы:**
  - `GET`: Получение данных с сервера.
  - `POST`: Отправка данных на сервер для создания нового ресурса.
  - `PUT`: Обновление существующего ресурса.
  - `DELETE`: Удаление ресурса.
  
- **Статусы HTTP-ответов:**
  - `200 OK`: Успешный запрос.
  - `201 Created`: Успешное создание ресурса.
  - `400 Bad Request`: Ошибка на стороне клиента (например, неверные параметры запроса).
  - `401 Unauthorized`: Отказ в доступе (например, неверный токен авторизации).
  - `404 Not Found`: Ресурс не найден.
  
- **JSON и XML:** Форматы обмена данными. JSON — наиболее популярный формат, так как он легче и проще в обработке.

**4. Аутентификация и авторизация:**
- **API ключи:** Простые ключи доступа, используемые для идентификации приложения или пользователя.
- **OAuth:** Стандарт авторизации, который позволяет приложениям запрашивать доступ к ресурсам от имени пользователя.
- **JWT (JSON Web Token):** Токен, который передаёт информацию о пользователе и используется для авторизации.

**5. Взаимодействие с API (Пример на Python):**

```python
import requests

# Пример GET-запроса
response = requests.get('https://api.example.com/data')
if response.status_code == 200:
    data = response.json()  # Получаем JSON-ответ и преобразуем его в словарь
    print(data)

# Пример POST-запроса
payload = {'name': 'John', 'email': 'john@example.com'}
response = requests.post('https://api.example.com/users', json=payload)
if response.status_code == 201:
    print('User created successfully')
```

**6. Использование API для обработки данных:**
- API позволяют загружать данные из внешних источников и обрабатывать их в реальном времени.
- **Пример:** Использование API для получения данных о курсах валют, которые потом можно анализировать и использовать для принятия решений.

**7. Ограничения API (Rate Limiting):**
- Многие API ограничивают количество запросов в минуту или час для предотвращения перегрузки.
- **Пример:** 1000 запросов в день или 10 запросов в минуту.

**8. Преимущества API:**
- **Интеграция систем:** Позволяет взаимодействовать с внешними сервисами (платежные системы, соцсети, базы данных и т.д.).
- **Автоматизация:** Программы могут автоматически получать и обрабатывать данные.
- **Удобство разработки:** Повторное использование сторонних сервисов и модулей.

**9. Недостатки API:**
- **Зависимость от внешних сервисов:** Если API недоступен, ваше приложение может потерять функционал.
- **Сложность настройки аутентификации и авторизации.**

Этот конспект поможет вам понять основы взаимодействия с API, их типы и как они используются для получения и обработки данных.

# Basic understanding of Data Structures and Algorithms: Familiarity with fundamental data structures (lists, dictionaries, sets, tuples, stacks, queues, trees, etc.) and algorithms (sorting, searching and others).

#### 1. **Структуры данных**

**1.1 Списки (Lists)**
- **Описание:** Упорядоченные коллекции элементов, поддерживающие индексацию.
- **Операции:** Добавление, удаление, вставка элементов, доступ по индексу.
- **Пример:** `my_list = [1, 2, 3]`
- **Преимущества:** Гибкость в размере, удобство доступа по индексу.
- **Недостатки:** Вставка/удаление в середине списка может быть медленной (O(n)).

**1.2 Словари (Dictionaries)**
- **Описание:** Неупорядоченные коллекции пар ключ-значение.
- **Операции:** Поиск, добавление, удаление по ключу.
- **Пример:** `my_dict = {'key1': 'value1', 'key2': 'value2'}`
- **Преимущества:** Быстрый доступ по ключу (O(1) в среднем).
- **Недостатки:** Не гарантируется порядок элементов (в старых версиях Python).

**1.3 Множества (Sets)**
- **Описание:** Неупорядоченные коллекции уникальных элементов.
- **Операции:** Добавление, удаление, объединение, пересечение, разность.
- **Пример:** `my_set = {1, 2, 3}`
- **Преимущества:** Быстрые операции с множествами, уникальность элементов.
- **Недостатки:** Нет доступа по индексу.

**1.4 Кортежи (Tuples)**
- **Описание:** Неизменяемые упорядоченные коллекции элементов.
- **Операции:** Доступ по индексу, создание срезов.
- **Пример:** `my_tuple = (1, 2, 3)`
- **Преимущества:** Быстрее, чем списки, благодаря неизменяемости.
- **Недостатки:** Нельзя изменять содержимое.

**1.5 Стек (Stack)**
- **Описание:** Последовательность элементов с доступом по принципу "последний вошел — первый вышел" (LIFO).
- **Операции:** `push` (добавить элемент), `pop` (удалить последний элемент).
- **Пример:** Используется для реализации рекурсии.
- **Преимущества:** Быстрая работа с последним элементом (O(1)).
- **Недостатки:** Ограниченный доступ к элементам (только последний).

**1.6 Очередь (Queue)**
- **Описание:** Структура данных с доступом по принципу "первый вошел — первый вышел" (FIFO).
- **Операции:** `enqueue` (добавление элемента), `dequeue` (удаление первого элемента).
- **Пример:** Используется в задачах планирования задач.
- **Преимущества:** Оптимальна для обработки элементов в порядке поступления.
- **Недостатки:** Ограниченный доступ к элементам.

**1.7 Деревья (Trees)**
- **Описание:** Иерархическая структура с корнем и дочерними узлами.
- **Типы:** Двоичные деревья, деревья поиска.
- **Операции:** Добавление, удаление узлов, обход (поиск).
- **Пример:** Двоичное дерево поиска (BST) используется для быстрой сортировки и поиска.
- **Преимущества:** Быстрый поиск, добавление и удаление элементов (O(log n)).
- **Недостатки:** Требует балансировки (в противном случае может деградировать до списка).

**1.8 Массивы (Arrays)**
- **Описание:** Линейная структура данных фиксированного размера, где хранятся элементы одного типа.
- **Операции:** Доступ по индексу (O(1)), вставка и удаление элементов требуют пересчета индексов (O(n)).
- **Пример:** В языках вроде C/C++, массивы используются для хранения данных одного типа, таких как числа или символы.
- **Преимущества:** Быстрый доступ к элементам по индексу.
- **Недостатки:** Фиксированный размер, невозможность изменения длины после создания.

**1.9 Связанные списки (Linked Lists)**
- **Описание:** Линейная структура данных, состоящая из элементов, называемых узлами, каждый из которых содержит данные и ссылку на следующий узел.
- **Типы:**
  - **Односвязный список:** Каждый узел содержит данные и указатель на следующий узел.
  - **Двусвязный список:** Каждый узел содержит указатели на предыдущий и следующий узел.
- **Операции:** Вставка и удаление элементов занимают O(1), но поиск элемента — O(n).
- **Пример:** `class Node { data; next; }`
- **Преимущества:** Динамический размер, вставка и удаление в произвольных позициях.
- **Недостатки:** Затраты памяти на хранение указателей, медленный доступ по индексу (O(n)).

**1.10 Хэш-таблицы (Hash Tables)**
- **Описание:** Структура данных, которая использует хэш-функцию для преобразования ключей в индексы в массиве.
- **Операции:** Добавление, удаление, поиск за O(1) в среднем случае.
- **Пример:** `my_dict = {'key1': 'value1', 'key2': 'value2'}` — это реализация хэш-таблицы в Python.
- **Преимущества:** Очень быстрые операции вставки и поиска по ключу.
- **Недостатки:** Возможны коллизии (разные ключи могут иметь один и тот же хэш).

**1.11 Графы (Graphs)**
- **Описание:** Нелинейная структура данных, состоящая из вершин (узлов) и рёбер, которые соединяют пары вершин.
- **Типы:**
  - **Ориентированные графы:** Рёбра имеют направление (например, веб-сайты с ссылками).
  - **Неориентированные графы:** Рёбра без направления (например, социальные сети).
  - **Взвешенные графы:** Каждому ребру присваивается вес (например, карты дорог).
- **Операции:** Поиск путей, обход вершин (DFS, BFS), нахождение кратчайшего пути (алгоритм Дейкстры).
- **Преимущества:** Гибкость в моделировании сложных систем (например, сети).
- **Недостатки:** Сложные алгоритмы обхода и анализа, высокая затратность по памяти.


#### 2. **Алгоритмы**

**2.1 Алгоритмы сортировки**
- **Bubble Sort:** Последовательное сравнение соседних элементов и их обмен при необходимости. O(n^2).
- **Selection Sort:** Поиск наименьшего элемента и перемещение его на нужную позицию. O(n^2).
- **Insertion Sort:** Вставка элемента на соответствующую позицию в отсортированной части списка. O(n^2).
- **Merge Sort:** Рекурсивное разделение массива на две части и их слияние. O(n log n).
- **Quick Sort:** Выбор опорного элемента, разделение массива на две части и рекурсивная сортировка. O(n log n).

**2.2 Алгоритмы поиска**
- **Линейный поиск:** Поиск элемента путем последовательного перебора всех элементов. O(n).
- **Бинарный поиск:** Поиск в отсортированном массиве, используя стратегию "разделяй и властвуй". O(log n).

**2.3 Рекурсия**
- Алгоритмы, где функция вызывает саму себя.
- Пример: Обход дерева, вычисление факториала.
- Недостатки: Возможность переполнения стека вызовов.

**2.4 Поиск в графах**
- **Поиск в глубину (DFS):** Проход по графу, начиная с глубинных узлов. Использует стек.
- **Поиск в ширину (BFS):** Проход по графу уровнями. Использует очередь.
